# Student Grade Manager

## How to run it

Download the Student Grade Repository, then navigate into the directory and then type python3 main.py in your terminal

## What is it

The user acts as a teacher who enters each students(you will be prompted to enter the number of students you will be entering information for) information which are their name,id and grade. Later each student's name,id,grade and if they passed or not will be displayed. And in the end the class average.
